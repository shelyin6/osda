# SQL 存储过程依赖分析工具

面向 DBA 的离线 Oracle SQL/PLSQL 静态分析工具。一期输入用户上传的 SQL 文件或粘贴代码，输出过程、函数、包体与表之间可追溯的读写依赖，用于跑批故障定位和影响范围分析。

## 当前状态

项目处于一期开发初始化阶段。当前已建立后端 API、领域模型、解析器边界和 Golden 测试目录；下一步接入 Oracle PL/SQL AST 解析器并实现依赖抽取。

## 本地要求

- Java 17 或更高版本（内网正式部署优先 Java 21）
- Maven 3.9 或更高版本

## 本地运行

```powershell
mvn spring-boot:run
```

服务启动后可访问 `GET /api/health`。

## 一期原则

- 仅静态分析；不连接数据库，不执行任何 SQL。
- 解析不确定时保留可用结果并输出告警。
- 动态 SQL 不伪造确定依赖。
- 解析核心使用 AST；不得以正则作为主要 SQL 分析方法。
